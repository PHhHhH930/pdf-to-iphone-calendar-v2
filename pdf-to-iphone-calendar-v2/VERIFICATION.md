# 核查记录（2026-09-29）

## 修正了什么

- 原来的星期列固定坐标已删除，改为读取七天表头与字符位置；无需固定姓名、课程名、字号或页面缩放。
- 修正单双周：例如 `2-8周(单)` 应为 3、5、7 周；支持双周、中文标点和列表。
- 不再跳过无法解析的课程块。遇到不完整表头、异常周次、未知节次时间等，停止转换。
- 从 PDF 自动读取各节起止时间，不静默沿用原样本的时间。
- 增加输出扩展名及覆盖保护、稳定 UID、重复事件去重、非法日期与时间检查。
- 西南大学南北区和楼号仍保留；更换学校名称不会悄悄附带西南大学坐标。

## 验证依据

- 原始两页真实课表：15个课程时段、131条日程。131条的课程标题、开始和结束日期时间与修改前基准全部一致；自动读取的14节时间也一致。
- 匿名实际 PDF：普通、缩放、旋转、跨页续接4份，每份均识别7个课程时段、21条日程，核对课程名、星期、周次、教师、教室与时间表。
- 自动化测试：运行 `python3 -m unittest discover -s tests -v`。包含12种缩放/平移/旋转组合、打乱PDF对象顺序、单双周、异常拒绝、日期、地点、UID、覆盖保护和实际PDF到ICS流程。
- ICS检查：CRLF换行、UTF-8每行不超过75字节、UTC起止时间、稳定且唯一UID、标准日历事件结构。

## 尚未验证与限制

- 没有其他真实学生课表样本；匿名PDF通过不等于所有教务系统模板都能识别。
- 当前仅 macOS 本地 CLI，无托管上传网页；七列文本课表需有◇/◆标记，不支持扫描件、缺少星期表头或任意排版。
- 不自动处理节假日、临时调课。必须提供第一周的周一。
- 没有在本轮重新写入 Apple 日历或验证手机同步，不把结构检查说成实机导入成功。
- 校园坐标不是教学楼门口坐标，客户端不一定显示地图。
- UID相对旧版本已变化，重复导入可能重复；建议先在新建专用日历核对。
- CI配置已增加macOS/Linux，但尚未上传GitHub，不能声称云端CI已通过。

公开包只含程序、文档和虚构测试数据，不包含原始个人PDF、生成日历或个人绝对路径。
