# PDF 课表转 iPhone 日历

把教务系统导出的课表 PDF 转成 Apple 日历可导入的 `.ics` 文件。程序读取课程、星期、节次、周次、校区、楼号、教室和教师，并把每周课程展开成独立日程。

目前适配西南大学这类带七天星期表头、◇/◆课程标记、节次与周次的文本型教务课表，运行于 macOS。不是只识别某个人的课程：星期列根据 PDF 表头定位，不包含姓名、具体课程名或固定页面坐标规则。项目不包含个人课表，仅包含虚构的测试 PDF。

这是本地命令行程序，不是已部署的上传网站。其他人下载项目后，把自己的 PDF 路径交给程序即可；文件不会发送到网络。Windows/Linux、扫描件和任意不同模板尚未支持。

## 使用

需要 macOS、Python 3.9 或更高版本和 Xcode Command Line Tools（提供 `clang`）。程序使用系统自带的 PDFKit，不需要安装 Python 第三方包。

```bash
python3 pdf_to_iphone_calendar.py \
  "/路径/你的课表.pdf" \
  --week1 2026-08-31 \
  --output "/路径/课表.ics" \
  --calendar-name "上课"
```

`--week1` 是第 1 周的周一，不能由 PDF 的学年名称推算。运行时会列出识别到的课程，请核对后再导入。程序不自动推断假期、调休或临时停课。

默认学校位置是西南大学北碚校区（UTC+8）。运行完成后，双击 `.ics` 文件，或在 Mac 日历里选择“文件 → 导入”。请先在 **iCloud** 下创建专用的“课程表”日历并导入其中；“在我的 Mac 上”日历不会自动同步到 iPhone。同一 iCloud 账户开启日历同步后，手机才能看到。

已有输出文件默认不覆盖；确认替换时加 `--force`。输出必须为 `.ics`，不能用 PDF 路径作为输出。日程 UID 不再依赖文件路径和课程排序，但不能保证所有日历客户端重复导入都会去重。旧版本与本版本的 UID 不同，建议导入新建的专用日历核对，不要直接重复导入旧课表日历。批量改颜色：更改这个专用日历的颜色即可。

第一次运行会自动用 `clang` 编译同目录的 PDFKit 小组件。若 Mac 尚未安装命令行工具，可在终端运行 `xcode-select --install`。

## 地点与地图定位

事件地点会带上“西南大学”及课表中的南区/北区。形如 `25-0709` 的场地会显示为“第25教学楼0709教室”；`未排地点` 会显示为“地点待定”。ICS 同时带有校内地图坐标，便于日历地图/导航功能定位到西南大学校园；地图点是校区级位置，楼号与教室保留在地点文字中。

学校名称、地址和地图坐标可通过参数更改：

```bash
python3 pdf_to_iphone_calendar.py "课表.pdf" \
  --week1 2026-08-31 \
  --university "西南大学" \
  --campus-address "重庆市北碚区天生路2号" \
  --campus-lat 29.82324 \
  --campus-lon 106.41835
```

默认校区地图坐标来自 OpenStreetMap 的西南大学地点数据（经 Mapcarta 展示）；坐标用于校园级地图定位，不代表某栋楼的门口坐标。西南大学官网确认第25教学楼为明德楼，并公布北碚校区地址；校方另有校园地图页面。

## 输入范围

要求 PDF 有可提取的文字，星期表头为“星期一…星期日”或“周一…周日”，七列规则排列，课程以 `◇` 或 `◆` 标记，后面有类似 `(1-2节)1-16周/校区:北区/场地:08-0606/教师:…` 的信息。支持标题换行、跨页续接、字号/缩放/旋转变化、单节和连续节次、单双周、单周与范围混合，以及全角括号和常见中文分隔符。

扫描件没有可提取文字，当前不做 OCR；缺少或重复星期表头、不规则列、无法完整解析的周次或课程块，会报错而不是默默略过。续页没有表头时，仅在页面尺寸及旋转一致时沿用上一页。严格检查仍不能保证任意未知 PDF 都不会误识别，导入前必须核对打印出的课程清单；目前尚无其他真实学生 PDF 的样本验证。

上课时间从 PDF 左侧的节次和起止时间自动读取，不再默认为某个人的作息表。PDF 缺少时间或样式无法识别时，需要显式提供 JSON（必须包含用到的每一节）：

```json
{
  "1": ["08:00", "08:45"],
  "2": ["08:55", "09:40"]
}
```

保存为 `times.json`，在转换命令末尾加 `--period-times times.json`。无效时间、逆序时间和重叠节次会被拒绝。改变 `--university` 后不再自动附带西南大学的地址或坐标；自定义学校仅改变地点文本，不代表已适配该校模板。`GEO` 是否显示地图取决于日历客户端，不能保证建筑级导航。

## 开发与检查

运行内置单元测试：

```bash
python3 -m unittest discover -s tests -v
```

测试包括周次/日期/地点/时间表验证、12 种几何变化、课程异常拒绝、稳定 UID、覆盖保护，以及 macOS 上 4 份匿名实际 PDF 的端到端转换（含跨页、缩放和旋转）。Linux 上仅运行纯 Python 测试，自动跳过 PDFKit 测试；CI 配置同时覆盖 macOS 与 Linux，实际 CI 结果需上传后查看。

`tests/fixtures/` 为虚构样本，可公开提交；可在 macOS 安装开发依赖 `reportlab` 后运行 `python3 tests/generate_fixtures.py` 重建，正常使用程序及运行已附测试不需要安装它。详细核查结果见 `VERIFICATION.md`。

课表 PDF 和生成的 `.ics` 可能包含个人信息，请勿一并提交到公开仓库。
